# Doc2Proto

서비스기획자의 상세기획서 PDF를 **인터랙티브 기획서**로 바꿔주는 서비스.
정적인 문서 대신 클릭해 볼 수 있는 기획서를 디자이너·개발자에게 URL로 전달해서,
기획 의도를 오해 없이 이해할 수 있게 하는 것이 목적이다.

## 사용법

1. https://doc2proto.vercel.app 에 접속해 상세기획서 PDF를 업로드 (또는 "샘플 기획서로 체험하기")
2. 변환은 전부 브라우저 안에서 일어난다 (pdf.js 기반, 서버로 전송 없음)
3. **인터랙션 모드** — 화면 기획의 점선 영역(핫스팟)을 클릭하면 해당 디스크립션이 하이라이트되고,
   설명 패널이 열린다. 반대로 디스크립션 영역을 클릭하면 화면 위치가 표시된다.
   버튼·기능 요소를 클릭하면 그 기능의 상세 페이지로 이동한다 (와이어프레임 프로토타입).
4. **인쇄 모드** — PDF 원본 그대로 페이지를 나열해 보여주고, 브라우저 인쇄를 지원한다.
5. **URL로 공유** — PDF를 저장소에 올리고 `?src=…` 링크를 복사한다. `#p=6&h=0` 형태의
   딥링크로 특정 페이지·핫스팟을 가리켜 공유할 수 있다.

## 구조

| 경로 | 역할 |
|---|---|
| `index.html` | 랜딩(업로드) + 뷰어 셸 |
| `js/analyzer.mjs` | PDF 오퍼레이터/텍스트 분석 — 빨간 점선 핫스팟, 연결 화살표, 디스크립션 블록, 페이지 간 프로토타입 링크 추출 |
| `js/main.mjs` | pdf.js 로딩, 페이지 렌더링, 모델 생성, URL 공유 |
| `js/app.js` | 뷰어 UI (인터랙션/인쇄 모드, 하이라이트, 딥링크) |
| `api/upload.js` | 공유용 PDF 업로드 (비공개 Vercel Blob, ≤4MB) |
| `api/file.js` | 공유된 PDF 열람 (`?id=` → Blob에서 스트리밍) |
| `vendor/pdfjs/` | pdf.js 배포본 (CDN 없이 동작) |
| `sample.pdf` | 샘플 상세기획서 |

## 배포 설정 (URL 공유 기능)

URL 공유는 Vercel Blob을 사용한다. Vercel 대시보드 → 프로젝트 → **Storage → Create → Blob**
스토어를 만들어 프로젝트에 연결하면 `BLOB_READ_WRITE_TOKEN`이 자동 주입되어 활성화된다.
연결 전에는 공유 버튼이 안내 메시지를 띄우고, 나머지 기능은 모두 동작한다.

## 인식 규칙 (분석기)

파워포인트 기획서 템플릿의 관행을 이용한다:

- **핫스팟**: 빨간 점선/실선 사각형
- **연결선**: 빨간 점(출발) → 점선 → 화살촉(도착). 화살촉이 가리키는 블록이 그 핫스팟의 설명
- **블록**: 텍스트·도형을 근접도로 클러스터링한 영역 (설명 표, 목업, 폼 등)
- **프로토타입 링크**: 같은 목업이 반복되는 다른 페이지의 핫스팟을 현재 페이지에 투영
