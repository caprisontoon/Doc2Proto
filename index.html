Doc2Proto

상세기획서를 원본 그대로 보여주면서, 화면은 실제로 동작하고 Description과 연결되는 문서로 전달해요.

올린 기획서는 어떻게 반영되나요?
  1. PPTX와 PowerPoint에서 내보낸 PDF를 올리면 GitHub 저장소에 들어가요.
  2. GitHub Actions가 자동으로 스냅샷·Description 연결을 만들고, 이전 버전이 있으면 변경 사항 비교와 동작 화면 복사까지 해요 (2~3분).
  3. 사이트가 다시 배포되면 목록에 새 버전이 나타나요.
  4. 기능이 바뀐 부분(새 버튼·새 상태 화면 등)의 동작 화면 반영은 로컬 Claude Code에서 /doc2proto로 이어서 해요.
PDF 빠른 미리보기 (브라우저 안에서만, 공유 안 됨)
PDF를 여기로 끌어오거나 클릭해서 선택

GitHub 연결

올리기·삭제는 저장소에 바로 커밋해요. 저장소 쓰기 권한이 있는 토큰이 필요해요. 토큰은 이 브라우저에만 저장돼요.

토큰 만들기 페이지 열기 ↗ (내 프로필 사진 → Settings → 맨 아래 Developer settings → Fine-grained tokens)
Repository access: 만 선택 · Permissions: Contents: Read and write, Actions: Read-only

새 버전 올리기

URL에 쓰여요: ?doc=docs/…/버전 (한글·영문·숫자·-)
📄PPTX 선택
🖼PDF 선택
PDF는 PowerPoint에서 파일 → 내보내기 → PDF로 만든 것이어야 원본과 똑같이 보여요.

기획서 삭제

삭제하면 공유된 링크가 더 이상 열리지 않아요. (저장소 기록에는 남아 있어 되살릴 수 있어요)
